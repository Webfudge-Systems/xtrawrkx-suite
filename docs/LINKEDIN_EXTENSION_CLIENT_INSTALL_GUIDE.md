# Xtrawrkx LinkedIn Extension Install Guide

This guide explains how to add the Xtrawrkx LinkedIn extension to Chrome and start using it with LinkedIn.

## What You Need

- Google Chrome installed
- Access to LinkedIn
- Your Xtrawrkx CRM login details
- The extension install link or extension ZIP/folder shared by the Xtrawrkx team

## Option 1: Install From Chrome Web Store

Use this option if the Xtrawrkx team shared a Chrome Web Store link.

1. Open the Chrome Web Store link shared with you.
2. Click **Add to Chrome**.
3. Click **Add extension** when Chrome asks for confirmation.
4. Wait for the extension to finish installing.
5. Click the puzzle icon in Chrome’s top-right toolbar.
6. Find **Xtrawrkx LinkedIn Extension**.
7. Click the pin icon so it stays visible in your toolbar.

The extension is now installed.

## Option 2: Install Manually For Testing

Use this option only if the Xtrawrkx team shared a ZIP file or folder for testing.

### If You Received A ZIP File

1. Download the ZIP file.
2. Extract/unzip it on your computer.
3. Remember the extracted folder location.

### Load The Extension In Chrome

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on **Developer mode** in the top-right corner.
4. Click **Load unpacked**.
5. Select the extracted extension folder.
6. Make sure the selected folder contains a file named `manifest.json`.
7. Click **Select Folder**.

The extension should now appear on the Chrome extensions page.

## Pin The Extension

1. Click the puzzle icon in Chrome’s top-right toolbar.
2. Find **Xtrawrkx LinkedIn Extension**.
3. Click the pin icon.

This keeps the extension visible while using LinkedIn.

## Sign In

1. Click the Xtrawrkx extension icon in Chrome.
2. Sign in using your Xtrawrkx CRM account.
3. If prompted, allow the extension to connect to the CRM.

## Using The Extension On LinkedIn

1. Open LinkedIn.
2. Visit a LinkedIn profile.
3. Open the Xtrawrkx extension/sidebar.
4. Review the detected profile details.
5. If the person has multiple roles, select the correct experience.
6. Click **Import to CRM**.

The profile will be added to the Xtrawrkx CRM.

## Updating The Extension

### Chrome Web Store Version

Chrome updates the extension automatically.

### Manual Testing Version

If the Xtrawrkx team sends a new ZIP or folder:

1. Extract the new ZIP if needed.
2. Go to `chrome://extensions`.
3. Find **Xtrawrkx LinkedIn Extension**.
4. Click **Remove** on the old version.
5. Click **Load unpacked**.
6. Select the new extracted extension folder.

## Troubleshooting

### Extension Is Not Visible

- Click the puzzle icon in Chrome.
- Pin the Xtrawrkx extension.
- Refresh LinkedIn.

### Import Button Does Not Work

- Make sure you are signed in to the extension.
- Refresh the LinkedIn profile page.
- Reopen the extension/sidebar.
- Try again after a few seconds.

### Wrong Or Missing Profile Details

- Scroll through the LinkedIn profile once so LinkedIn loads all sections.
- Refresh the page.
- Open the extension again.
- Select the correct experience before importing.

### CRM Login Fails

- Confirm your email and password.
- Check that you have access to the Xtrawrkx CRM.
- Contact the Xtrawrkx team if your account is not active.

## Support

If you face any issue, share the following with the Xtrawrkx team:

- Your Chrome version
- A screenshot of the issue
- The LinkedIn profile URL where the issue happened
- Whether you installed from Chrome Web Store or manually
